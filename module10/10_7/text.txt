Как инициализируются слайсы в Go:

var intArr = []int {1,2,4,5,6}
var stringArr = []string{"one", "two", "three"}


// элементом слайса может быть любой тип, в т.ч. слайс
var matrix = [][]int{
    []int{0, 1},
    []int{3, 4},
}
У каждого элемента слайса есть свой индекс (порядковый номер, начинается с нуля).

Доступ к элементу слайса можно получить по индексу, например:

firstElement := intArr[0] // firstElement == 1
Можно перебрать все элементы слайса с помощью цикла for:

for i, value := range stringArr { 
    fmt.Println(i, value) 
}


/*Output:
0 one
1 two
2 three
*/
Можно изменить значение по индексу после инициализации массива:

fmt.Println(matrix) // Output: [[0 1] [3 4]] 
	
matrix[1] = []int{5, 6}
fmt.Println(matrix) // Output: [[0 1] [5 6]]
Длину слайса можно узнать с помощью функции len(), а вместимость с помощью cap().

Инициализировать слайс с заранее заданной длиной и вместимостью можно с помощью функции make():

ar := make([]int, 2, 4)
fmt.Println(len(ar), cap(ar), ar) // Output: 2 4 [0 0]
	
sar := make([]string, 2, 4)
fmt.Println(len(sar), cap(sar), sar) // Output: 2 4 [ ] ← two empty strings
	
par := make([]*struct{}, 2, 4)
fmt.Println(len(par), cap(par), par) // Output: 2 4 [<nil> <nil>]
А теперь давайте на примерах разберёмся, как работать с массивами.

Примечание!
Слово массив используется как обозначение структуры данных «массив», а не как обозначение типа array в Go. Использовать в коде мы всё равно будем слайсы.
Максимальный отрицательный элемент массива
Давайте для начала напишем функцию, которая просто найдёт максимальный элемент массива. Кажется, всё просто: нужно перебрать все элементы и поочередно сравнить каждый с… с чем? Наверное, с каким-то очень маленьким числом, меньше которого точно быть не может в массиве.

func findMax(array []int) (max int) {
	max = math.MinInt64
	for _, val := range array {
		if val > max {
			max = val
		}
	}

	return max
}
Примечание!
math.MinInt64 — это переменная из стандартного пакета math, в которой содержится минимальное число, которое можно записать в переменную типа int64.
Посмотрите на получившуюся функцию. Как вы думаете, какие могут быть проблемы?

В функцию могут передать пустой слайс, в таком случае она вернёт math.MinInt64. Очевидно, это неправильно. Но что делать? Что можно вернуть? Любое значение, которое мы вернём, нельзя будет идентифицировать как отсутствие максимального элемента.

Обычно такие проблемы решают тремя способами:

Используют поинтеры findMax(array []int) (max *int) (вернётся nil, если максимального элемента не существует). Сомнительное решение, но имеет право на жизнь.
Используют флаг, который показывает, успешно или нет отработала функция findMax(array []int) (max int, found bool). Если максимальный элемент не найден, то возвращается found==false, иначе — true. Хороший способ, когда нам не важна причина неудачи исполнения функции.
Используют error, который показывает, произошла ли какая-то ошибка во время выполнения findMax(array []int) (max int, err error). Если err != nil, то произошла ошибка. Самый каноничный для Go способ. Более многословный, чем 2 пункт, но гораздо более гибкий. В дальнейших уроках вы научитесь правильно обрабатывать ошибки, а пока просто примите это на веру.
func findMax(array []int) (max int, err error) {
	if len(array) == 0 {
		return 0, fmt.Errorf("could not found max in empty slice")
	}

	max = math.MinInt64
	for _, val := range array {
		if val > max {
			max = val
		}
	}

	return max, nil
}
По-моему, уже выглядит лучше. Также можно использовать следующий вариант, что бы не пришлось импортировать пакет math:

func findMax(array []int) (max int, err error) {
	if len(array) == 0 {
		return 0, fmt.Errorf("could not found max in empty slice")
	}

	max = array[0]
	for _, val := range array[1:] {
		if val > max {
			max = val
		}
	}

	return max, nil
}
В данном случае мы изначально берём за max первый элемент массива, и в цикл передаём массив без первого элемента.

Задача №1
А теперь напишите функцию findMaxNegative(), которая вернёт максимальное отрицательное число (а в случае отсутствия отрицательных чисел — ошибку).

Число, чаще всего встречающееся в массиве
Давайте решать в лоб. Для начала подумаем, что нам нужно сделать? Нам нужно каждое число в массиве последовательно сравнить со всеми остальными числами, подсчитать, сколько раз число встречается, и сравнить с частотой остальных чисел.

Внимательно изучите пример и разберитесь, как это работает:

func findMostOftenRepeated(array []int) (mostOften int, err error) {
	if len(array) == 0 {
		return 0, fmt.Errorf("could not found repeated numbers in empty slice")
	}

	var maxIndex, maxCount = 0, 0
	for i, number := range array {
		currentCount := 0
		for _, numberToCompare := range array {
			if number == numberToCompare {
				currentCount++
			}
		}

		if currentCount > maxCount {
			maxIndex = i
			maxCount = currentCount
		}
	}

	return array[maxIndex], nil
}
